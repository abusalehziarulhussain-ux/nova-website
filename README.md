# Ari Vale Portfolio

A portfolio website for a multidisciplinary designer and developer.

## Features

- Personalized portfolio landing page
- Case study cards with project metrics
- Services section
- Testimonial section
- Working contact form with backend handler
- Vercel-ready app structure

## Form setup

Add one of these environment variables before deploying:

```bash
FORM_ENDPOINT=https://formspree.io/f/your-form-id
# OR
RESEND_API_KEY=your_resend_api_key
CONTACT_EMAIL=you@example.com
```

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Deploy to Vercel

1. Push this repo to GitHub
2. Import it into Vercel
3. Add the environment variables above in Vercel Project Settings
4. Deploy
